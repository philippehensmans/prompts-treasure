# Dossier pour les images

Placez votre logo ici avec l'un de ces noms :
- `logo.png` (recommandé)
- `logo.jpg`
- `logo.svg`

Le logo sera automatiquement affiché dans la bannière.

## Recommandations pour le logo :

- **Format recommandé :** PNG avec fond transparent
- **Dimensions :** Hauteur de 40-80px (largeur proportionnelle)
- **Poids :** Moins de 100 Ko pour un chargement rapide

Si aucun logo n'est trouvé, l'icône 📝 sera affichée par défaut.
